Runtimes

Four kinds of pod.
One cluster.

Pick one with runtimeClassName. kvz creates the RuntimeClasses for you.

  1. linuxdefault

    Each pod boots its own small Linux VM through Virtualization.framework, cold, every time.

  2. macos

    A full macOS virtual machine with a copy-on-write disk. Great for macOS CI and clean test machines.

  3. darwin

    Native macOS processes on the host. For Xcode, code signing and the GPU.

  4. apple

    A container run by Apple's container tool. kvz's first runtime, kept as a baseline.
